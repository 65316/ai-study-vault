# 🎓 AI 自学舱（AI Study Vault）

> **Obsidian × AI 智能体 × 网页版免费对话**的交互学习系统模板。
> 克隆 → 打开 → 说一句「帮我学XX」，AI 家教开课；学完去内置浏览器开免费网页版重复刷，token 省一半，理解深一层。

## ⚡ 一句话部署

把这句话发给**任意 AI**（Claude Code / Codex / Claudian / DeepSeek / Kimi / 千问网页版都行），AI 会自己读取本仓库并带你装完全套：

```text
请读取 https://github.com/65316/ai-study-vault 这个仓库，按里面的安装剧本帮我部署这套学习系统
```

> 有终端权限的 AI（Claude Code / Codex）会自动 clone → 检测环境 → 装依赖 → 配置 → 验证；网页版 AI 会引导你逐步操作。全程只有三类事必须你亲手做：**注册大模型平台账号、创建并填入 API Key、在 Obsidian 里点几下装插件**——其余全自动。

## 🧩 系统架构

```
Obsidian（笔记本体，免费）
├── Claudian 插件 ──── 对接 Claude Code / Codex 智能体
│      └── 多供应商切换：DeepSeek / Kimi / GLM / 千问 / 中转站
├── Surfing 浏览器插件 ── 内置浏览器收藏 AI 网页版书签（免费额度）
├── 看图助手 tools/vision.py ── 图题转文字（填一个 api_key 即用）
└── vault 结构 + CLAUDE.md 教学规则

双轨学习闭环：
┌─ 智能体轨道（花 token，干精细活）
│    首讲知识点 · 写笔记沉淀 · 出题批改 · 错题归档 · 日志进度
└─ 网页版轨道（免费，干重复活）
     同一知识点多平台免费复读 · 对比阅读 · 加深理解
```

## ✨ 特性

- **四步教学循环**：大白话解释 → 举具体例子 → 出题检验 → 记忆口诀，AI 按固定套路上课，不跳步
- **三段式笔记**：题目（全）→ 答案（公式→代入→结果）→ 总结（口诀+速查表），可折叠答案不剧透
- **Obsidian 原生**：WikiLinks 双链、`> [!答案]-` 可折叠答案、KaTeX 公式渲染
- **图片即贴即用**：附件自动归位到图片库 + Image Toolkit 插件点击浮现放大
- **看图助手**：DeepSeek 网页版看不了图？草稿区 + 视觉 API 一键把图题转文字（默认走阿里云百炼，新用户免费额度，只填一个 api_key）
- **双轨学习法**：智能体干精细活，网页版免费刷重复，token 成本砍半
- **多供应商**：CC Switch 一键切换 DeepSeek / Kimi / GLM / 千问，哪家便宜用哪家
- **学习留痕**：学习记录 + 会话日志，进度永不丢

## 🚀 快速开始

1. **克隆仓库**：
   ```bash
   git clone https://github.com/65316/ai-study-vault.git 我的笔记本
   ```
   （没有 git？浏览器打开仓库 → Code → Download ZIP → 解压，效果一样）
2. **让 AI 帮你装**：把 [docs/00_AI安装助手.md](docs/00_AI安装助手.md) 这个文件发给任意 AI（Claudian 对话框、DeepSeek/Kimi/千问网页版都行），说「**帮我安装**」——AI 会逐项检测你的环境、给出对应命令、带你装到能跑为止
3. **初始化**：对 AI 说「**初始化**」，完成三个个人配置任务（学员画像 / 学习规则 / 看图助手）
4. **开课**：说「帮我学 C 语言指针」，四步循环开始上课

> 喜欢自己动手？[docs/01_环境安装.md](docs/01_环境安装.md) 是同样的内容，手动的版本。
> 装完之后还有 **5 个必做配置任务**（注册账号 / 对接 Key / 画像 / 规则），原因和步骤都写在 [docs/03_配置任务清单.md](docs/03_配置任务清单.md)。

> 💡 没装 Claude Code？把 `CLAUDE.md` 全文粘给任意 AI（DeepSeek/Kimi/千问网页版）当系统提示词，也能获得同款教学，只是没有自动记笔记。
