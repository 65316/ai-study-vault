# 🎓 AI 自学舱（AI Study Vault）

> **Obsidian × AI 智能体 × 网页版免费对话**的交互学习系统。
> 一句「帮我学XX」开课，学完去免费网页版重复刷，token 省一半，理解深一层。

> **这套系统怎么来的**：把常用的 Obsidian 笔记软件接上 AI，就是一台随身「AI 私人家教」。国外 Claude Code / Codex 官方版用不起，就用 CC Switch 把 Claude Code 这个「外壳」接到国产 API 和自己的中转站当大脑（DeepSeek / Kimi / GLM / 千问 都能切）；日常在 Claudian 插件面板里对话，Obsidian 左目录、中笔记、右助手三栏布局。再用 Surfing 网页插件内置免费 AI 对话，不切平台就能用——预设三个平台、可自己加，安装时 AI 辅助配好，减少 API 消耗、合理利用免费资源，多平台还避免单一被卡。DeepSeek 没有视觉？接入阿里云百炼免费额度做看图助手。一句话：**一套不花大钱的大学生个人自学系统**。

## 🔧 系统结构（它怎么工作）

> **定位**：大学生个人自学系统——把常用的 Obsidian 变成随身 AI 家教，还能尽量不花 API 钱。

**为什么这么搭（三步动机）**：
1. Obsidian 本来就是好用的笔记软件 → 接入 AI，变成「私人家教」
2. 国外 Claude Code / Codex 官方付费、用不起 → 用 CC Switch 把 Claude Code 这个「外壳」接到**国产 API 和你自己的中转站**（DeepSeek / Kimi / GLM / 千问 都能切）当大脑
3. API 按量也花钱 → 再挂一条**免费轨道**：Surfing 内置浏览器直接开网页版免费 AI 复读，减少 API 消耗、防单一平台被卡；DeepSeek 没有视觉 → 用阿里云百炼免费额度做看图助手

**界面长这样**（Obsidian 三栏）：

```
┌──────────┬──────────────┬──────────────┐
│   目录     │    内容笔记    │   AI 助手     │
│ 01_学习计划 │  三段式笔记   │  Claudian 面板│
│ 02_学科笔记 │  题目→答案→   │  ＋ Surfing   │
│ 90_图片    │    总结      │  内置网页      │
└──────────┴──────────────┴──────────────┘
```

**四个角色**：

| 角色 | 是谁 | 干什么 |
|:--|:--|:--|
| 界面 | Obsidian + Claudian / Surfing / Image Toolkit | 左目录、中笔记、右助手；Surfing 让你不切平台就用网页版免费 AI |
| 引擎 | Claude Code / Codex CLI | 只是「外壳」AI 家教：读画像、四步教学、写三段式笔记 |
| 大脑 | 大模型 API | 真正思考的国产模型 / 你的中转站；CC Switch 一键切换 |
| 省钱轨道 | 网页版免费 AI + 看图助手 | 教完去 dp / kimi / 千问免费复读；截图走百炼 vision.py 转文字 |

**供应商策略**：CC Switch 里预设三个平台，你可以自己加；安装时 AI 辅助给你配好，Key 只由你自己填。

**三条工作流**：

1. **教学流（学进去）**：面板说「帮我学X」→ 引擎读 `01_学习计划/` 里的画像 → 四步循环（大白话→例子→出题→口诀）→ 笔记落进 `02_学科笔记/` → 学习记录与会话日志即时更新，进度永不丢
2. **双轨流（忘不了）**：智能体花 token 教一遍 → 同一知识点去 DeepSeek / Kimi / 千问网页版免费各问一遍 → 图题先 `vision.py` 转文字 → 省钱又加深记忆
3. **对焦学习（B 站视频）**：Surfing 内置浏览器直接看 B 站课程 → 遇到不懂的知识点就截图 → `vision.py` 转成文字问 AI → 对照自己的 `02_学科笔记/` 补缺强化 → 当场沉淀成新笔记

## ⚡ 方式一：AI 一键安装（推荐）

把下面这段话**原样发给任意 AI**（Claude Code / Codex / Claudian / DeepSeek / Kimi / 千问网页版都行）：

```text
请读取 https://github.com/65316/ai-study-vault 这个仓库，按里面的安装剧本帮我部署这套学习系统
```

AI 会自动完成：clone 仓库 → 检测环境 → 装 Node/Python/Claude Code → 下载 CC Switch 和三个 Obsidian 插件 → 配置看图助手 → 验证开课。

**你只需要亲手做 3 件事**：①注册大模型平台账号 ②把 API Key 粘进配置 ③在 Obsidian 里关闭一次限制模式。其余全部 AI 代劳。

> 想先看 AI 会执行什么？剧本全在这里：[docs/00_AI安装助手.md](docs/00_AI安装助手.md)

## 🛠 方式二：手动安装（约 15 分钟）

0. **获取模板**：`git clone https://github.com/65316/ai-study-vault.git 我的笔记本`，或浏览器打开仓库 Code → **Download ZIP** → 解压
1. **装 Obsidian**（https://obsidian.md ）→ 「打开本地仓库文件夹」选择第 0 步的目录 → **设置 → 第三方插件 → 关掉「限制模式」**（不关装不了插件）
2. **装 Node.js 18+**（https://nodejs.org ）→ `npm install -g @anthropic-ai/claude-code`
3. **装 CC Switch** 配置大模型平台（Windows 一条命令：`winget install -e --id farion1231.CC-Switch`）→ 填入平台端点和你的 Key
4. **Obsidian 插件装三个**：`Claudian`（对话 AI）、`Image Toolkit`（点击图片放大）、`Surfing`（内置浏览器）——最省事是终端对 AI 说「帮我装 Obsidian 的三个插件」代装
5. 终端运行 `claude` → 说「**初始化**」

> 图文详解：[docs/01_环境安装.md](docs/01_环境安装.md)

## 📋 装完之后：5 个配置任务（约 15 分钟）

注册平台 Key → 对接智能体 → 对接看图助手 → 完善学员画像 → 定制学习规则
每项的「为什么 + 步骤」：[docs/03_配置任务清单.md](docs/03_配置任务清单.md)（也可以对 AI 说「初始化」，让它带你做）

> 💡 **「初始化 3 任务」vs「配置 5 任务」的对应**：对 AI 说「初始化」后它带你做 **3 个任务**（①完善画像 ②定制规则 ③搭建看图助手）；再算上之前**注册平台 + 填 Key**（任务 1、2），正好是配置清单的 **5 个任务**：
> `5 任务 = 2 个"账号与钥匙"（注册 + 对接） + 3 个"初始化任务"（画像 + 规则 + 看图）`

## ✨ 功能亮点

- **四步教学循环**：大白话 → 例子 → 出题 → 口诀，AI 按固定套路上课，不跳步、不说教
- **三段式笔记**：题目（全）→ 答案（公式→代入→结果）→ 总结（口诀+速查表），`> [!答案]-` 可折叠答案不剧透
- **图片即贴即用**：截图自动归位图片库 + Image Toolkit 点击浮现放大
- **多供应商自由切**：DeepSeek / Kimi / GLM / 千问 / 中转站，哪家便宜用哪家
- **学习留痕**：学习记录 + 会话日志，进度永不丢，新对话自动恢复上下文

## 🎬 上课效果长这样

> 你：帮我学 C 语言指针
>
> AI：**① 大白话**——指针就是「存门牌号的纸条」：变量是房间，指针是写着别的房间门牌号的纸条…
> **② 例子**——`int *p = &a; *p = 10;` 每行配大白话注释，运行结果算给你看
> **③ 出题**——「这段代码输出什么？」（答案折叠，做完再展开，三步法解析）
> **④ 口诀**——`&` 取地址，`*` 顺藤摸瓜；纸条不指门，写字就塌家
