# 🎓 AI 自学舱（AI Study Vault）

> **Obsidian × AI 智能体 × 网页版免费对话**的交互学习系统模板。
> 克隆 → 打开 → 说一句「帮我学XX」，AI 家教开课；学完去内置浏览器开免费网页版重复刷，token 省一半，理解深一层。

---

## 🧩 系统架构

```
Obsidian（笔记本体，免费）
├── Claudian 插件 ──── 对接 Claude Code / Codex 智能体
│      └── 多供应商切换：DeepSeek / Kimi / GLM / 千问 / 中转站
├── 内置浏览器 ──────── 收藏 AI 网页版书签（免费额度）
└── vault 结构 + CLAUDE.md 教学规则

双轨学习闭环：
┌─ 智能体轨道（花 token，干精细活）
│    首讲知识点 · 写笔记沉淀 · 出题批改 · 错题归档 · 日志进度
└─ 网页版轨道（免费，干重复活）
     同一知识点多平台免费复读 · 对比阅读 · 加深理解
```

## ✨ 特性

- **四步教学循环**：大白话解释 → 举具体例子 → 出题检验 → 记忆口诀，AI 按固定套路上课，不跳步
- **三段式笔记**：题目（全）→ 答案（公式→代入→结果）→ 总结（口诀+速查表），可折叠答案不剧透
- **Obsidian 原生**：WikiLinks 双链、`> [!答案]-` 可折叠答案、KaTeX 公式渲染
- **双轨学习法**：智能体干精细活，网页版免费刷重复，token 成本砍半
- **多供应商**：CC Switch 一键切换 DeepSeek / Kimi / GLM / 千问，哪家便宜用哪家
- **学习留痕**：学习记录 + 会话日志 + 错题本，进度永不丢

## 🚀 快速开始

1. **装环境**：跟 [docs/01_环境安装.md](docs/01_环境安装.md) 一步步装（约 15 分钟）
2. **克隆本仓库**：
   ```bash
   git clone https://github.com/65316/ai-study-vault.git 我的笔记本
   ```
3. **开课**：Obsidian 打开该文件夹为仓库，终端 `cd` 进去运行 `claude`，说「帮我学 C 语言指针」

> 💡 没装 Claude Code？把 `CLAUDE.md` 全文粘给任意 AI（DeepSeek/Kimi/千问网页版）当系统提示词，也能获得同款教学，只是没有自动记笔记。
