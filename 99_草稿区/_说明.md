# 草稿区 — 看图中转站

> **为什么存在？** DeepSeek 等网页版 AI 免费但**看不了图**。本区就是把图片题目"转文字"的中转站，让免费网页版也能做图题。

## 工作流

```
① 把题目截图粘贴到本文件夹的笔记里（图片自动存进 90_图片/）
② 让智能体「看草稿区最新一张图」：
   python tools/vision.py "90_图片/xxx.png" "把图里的题目完整转成文字，保留公式"
③ 复制转好的文字题目 → 去 DeepSeek / Kimi / 千问 网页版免费提问
④ 处理完的草稿定期清空，保持本区干净
```

> 智能体侧的规则写在 CLAUDE.md「看图规则」，学员只需填一次 `tools/vision_config.json` 的 api_key。
