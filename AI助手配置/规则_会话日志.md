# 📓 学习记录与会话日志规则

| # | 规则 |
|:-:|:----|
| 1 | **对话中即时更新**，不等结束：学了新知识点立刻写进学习记录，每轮教学立刻追加会话日志，不准攒到对话结束批量处理 |
| 2 | 学习记录：`01_学习计划/学习记录.md`（目标、进度、倒计时、学员画像） |
| 3 | 会话日志：`04_会话日志/学习会话日志.md` 记明细；`04_会话日志/会话日志.md` 只保留总索引 + 最近一次摘要 |
| 4 | 子日志格式：`| 时间段 | 状态 | 干了什么 |` |
| 5 | 新对话开始时先读总索引 + 学习记录，恢复上下文再开课 |
| 6 | **T0/T1/T2 三级压缩**：近 5 天保持详细（T0）→ 旧条目压缩为摘要表（T1）→ 可复用学习方法提取到 `AI助手配置/`（T2）。不准一刀切删除，旧条目保持可追溯 |
| 7 | **硬性刹车**：每完成一项实质性工作（讲完一个知识点/写完一篇笔记），先更新对应记录再回答下一个问题 |
