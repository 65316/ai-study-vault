# 🎯 对焦学习法：视频 → 截图 → 提问 → 笔记

> 一句话：Surfing 里看 B 站课程，遇到不懂的截图转文字问 AI，再对照自己的笔记精准补缺——把「别人的课」变成「自己的知识」。
> 和双轨学习法互补：**双轨管「重复记忆」，对焦管「精准补缺」**。

## 为什么对焦

| 痛点 | 对焦解法 |
|:----|:----|
| B 站课是别人的，看一遍就忘 | 截图 + 提问 + 沉淀，当场过一遍手才进脑子 |
| 视频里一个小点不懂，整节课卡住 | 精准揪出那个点，问明白再往下看 |
| 网页版 AI 看不了图 | `vision.py` 走百炼免费额度转文字 |
| 看完视频不知道笔记从哪补 | 对照已有 `02_学科笔记/`，只补缺口不重复学 |

## 五步闭环

```
① Surfing 打开 B 站看课（不切平台）
② 遇到不懂 → 截图（Win：Win+Shift+S / Mac：三指截图）
③ 截图丢进 99_草稿区/ → 对 AI 说「看草稿区最新一张图，转成文字」
④ 拿文字去问 AI（Claudian 面板 或 网页版 dp/kimi/千问），问到懂为止
⑤ 对照 02_学科笔记/ 找缺口 → 三段式沉淀成新笔记 → 清空草稿区
```

## 给 AI 的提问话术

直接复制用：

```text
看草稿区最新一张图，把知识点完整转成文字，保留公式。
```

```text
这个知识点和我正在学的【X】有什么关系？用大白话讲一遍。
```

```text
我笔记里关于【Y】的理解是这样的：（你的理解）。这段视频补充了什么？我哪里理解偏了？
```

## 和双轨学习法的配合

| 场景 | 走哪个 |
|:----|:----|
| 看视频卡住一个点 | 🎯 **对焦学习**（精准补缺） |
| 学完想加深记忆 | 🌐 **双轨学习**（免费复读） |
| 想省钱 | 两者都是：能自己看懂的绝不花 token，卡住的才问 AI |

## 小提示

- 截图用英文 / 数字文件名（如 `img1.png`），避免中文路径报错
- 看完一节沉淀一节，别攒一堆
- 笔记开头标「来源：B站 UP 主 XXX」，方便回看
- 沉淀完草稿区随手清空，保持收集箱常空常新
