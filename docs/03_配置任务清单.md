# 📋 安装后配置任务清单

> **装完 ≠ 能用。** 以下任务只有你本人能完成（AI 代不了：涉及你的账号、你的 Key、你的学习偏好）。
> 每个任务都写了「为什么」和「步骤」，按顺序做，全程约 20 分钟。做完后 AI 就完全是你的私人家教了。

## 总览

| # | 任务 | 为什么必须你本人做 | 耗时 |
|:-:|:----|:----|:----|
| 1 | 注册大模型平台 + 创建 API Key | 账号实名注册只能本人操作；Key 等于钱包钥匙 | ~5 分钟 |
| 2 | 对接智能体（Claude Code × 你的 Key） | Key 不该发给任何 AI，需要你自己填进配置 | ~3 分钟 |

| 4 | 完善学员画像 | 你的学段/科目/节奏 AI 无法猜测 | ~3 分钟 |

| 6 | 对接 GitHub 云端备份 | 笔记是你的全部资产；私有仓免费备份、多设备同步 | ~5 分钟 |

## 第一类：账号与钥匙

### 任务 1 · 注册大模型平台并创建 API Key

**为什么**：Claude Code 只是「外壳」，真正思考的是背后的大模型；看图助手也需要一个视觉模型的 Key。没有 Key，一切转不动。

**步骤**：

1. 选一个平台注册（可多选，配 CC Switch 随时切）：

| 平台 | 注册入口 | 提示 |
|:----|:----|:----|
| DeepSeek | platform.deepseek.com | 按量付费，价格低 |
| Moonshot Kimi | platform.moonshot.cn | 有免费/低价档 |
| 智谱 GLM | bigmodel.cn | **有永久免费模型档** |
| 阿里云百炼 | bailian.console.aliyun.com | **新用户各模型自动送免费额度**（推荐，视觉也用它） |

2. 完成实名认证（各平台要求不同，跟页面走）
3. 控制台里找到「API Key」→ 创建 → **立刻复制保存到本地**
4. ⚠️ 安全铁律：Key 只填进配置文件，**不要发给任何 AI、不要贴进对话、不要提交到 git**

### 任务 2 · 对接智能体（让 Claude Code 用上你的 Key）

**为什么**：Claudian 对话框里的 AI 就是本机 Claude Code，要先告诉它「去哪个平台、用哪把钥匙」。

**步骤**（二选一）：

- **路线 A · 图形化（推荐）**：装开源工具 **CC Switch** → 把平台端点 + 你的 Key 存成供应商条目 → 一键切换
  - 💡 **AI 可代劳下载安装**：对 AI 说「帮我装 CC Switch」，Windows 下它会跑一条命令：`winget install -e --id farion1231.CC-Switch`（winget 官方源，免手动下载）；macOS 去 https://github.com/farion1231/cc-switch/releases 下 `.dmg`
  - 装好后「添加供应商」条目里的 Key 还是你自己粘
- **路线 B · 手动**：设置两个环境变量后重开终端：
  ```
  ANTHROPIC_BASE_URL   = 平台端点（见 docs/01_环境安装.md 第4节表格）
  ANTHROPIC_AUTH_TOKEN = 你的 Key
  ```

**验证**：在仓库目录运行 `claude`，随便问一句话，有回复即通。

### 任务 3 · 对接看图助手（视觉 API）

**为什么**：DeepSeek 网页版免费但**看不了图**。看图助手把题目截图转成文字，图题也能拿去网页版免费问（默认走阿里云百炼，用任务 1 注册的账号即可）。

**步骤**：

1. 复制 `tools/vision_config.example.json` 为 `tools/vision_config.json`（直接改名即可），再用文本编辑器打开它
2. 把 `api_key` 换成你自己的 Key（默认端点和模型就是百炼，不用动）：
   ```json
   {
     "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
     "api_key": "你的Key",
     "model": "qwen-vl-max"
   }
   ```
3. 放任意一张截图进 `90_图片/`，终端验证：
   ```bash
   python tools/vision.py "90_图片/任意图.png" "图里写了什么？"
   ```
4. 报错对照：401/403 = Key 填错或服务没开通；404 = 端点写错（必须以 `/v1` 结尾）

> 你把 Key 填进 `vision_config.json` 之后，如果以后要把自己这份仓库推到公开托管，记得先把它加进 `.gitignore`。

## 第二类：个人化（跟 AI 对话完成）

### 任务 4 · 完善学员画像

**为什么**：AI 出题的难度、讲的深度、举例的风格，全部由画像定调。画像空白，AI 只能按"平均用户"瞎猜。

**步骤**：

1. 对 AI 说：「**初始化**」
2. AI 会问你 4 件事，照实回答：
   - 学段目标（期末备考 / 考研 / 自学入门 / 兴趣学习）
   - 在学科目（高数 / C 语言 / 物理 / 英语……）
   - 笔记风格偏好（截图为主 / 纯文字 / 大纲式）
   - 节奏偏好（默认：快节奏、废话少、干货多）
3. AI 写入 `01_学习计划/学习记录.md` → 你随时可以打开手改

### 任务 5 · 定制学习规则

**为什么**：仓库自带的 `AI助手配置/` 是通用教学规则。你的科目常考题型、希望重点练什么、笔记怎么排——写成定制规则后，AI 每次上课都会优先遵守。

**步骤**：

1. 对 AI 说（示例）：「帮我定制规则：我在学 C 语言和物理，期末考，物理要重点练计算大题，笔记里代码注释每行都要」
2. AI 生成 `AI助手配置/我的规则.md`
3. 之后所有教学，`我的规则.md` 优先于默认规则；想改随时说

## 第三类：数据备份（可选，但强烈推荐）

### 任务 6 · 对接 GitHub 云端备份

**为什么**：笔记和进度是你在这套系统里攒下的全部资产。本地电脑可能坏、可能丢；GitHub 私有仓库免费，放一份上去等于买保险，还能多设备同步、换电脑不心疼。

**步骤**：

1. 注册 GitHub（https://github.com ）→ 右上角 **New repository** → 建一个 **Private（私有）** 仓库，名字随意（如 `my-notes`）——**别选 Public**，学习笔记是私人数据
2. 本仓库关联到你的 GitHub（在仓库目录终端执行，把 `你的用户名/你的仓库名` 换成你自己的）：
   - **git clone 来的**：直接改远程地址
     ```bash
     git remote set-url origin https://github.com/你的用户名/你的仓库名.git
     ```
   - **ZIP 解压的**（没有 .git）：先初始化再关联
     ```bash
     git init
     git add -A && git commit -m "first backup"
     git remote add origin https://github.com/你的用户名/你的仓库名.git
     ```
   > 从模板 clone 的远程默认指向 `65316/AI-Tutor`，改远程地址就是把它换成你的仓库
3. 推送 + 首次认证：
   ```bash
   git push -u origin main
   ```
   认证二选一：
   - **Token（简单）**：GitHub → Settings → Developer settings → Personal access tokens → Generate new token → 勾 `repo` 权限 → 复制；push 时用户名填你的 GitHub 用户名、密码粘贴 token
   - **SSH（一劳永逸）**：配好 SSH key 后 push 免密（教程搜 "GitHub SSH key"）
4. 验证：`git push` 成功，GitHub 网页能看到笔记 → 以后学完对 AI 说「**帮我提交备份**」即可

**安全铁律**：仓库必须 **Private**；`tools/vision_config.json` 已自动进 `.gitignore`，你的中转站 `base_url` / Key 这类也**不要手动提交**到仓库。
