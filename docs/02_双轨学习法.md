# 双轨学习法：智能体 × 网页版

> 这套系统的省钱核心：**token 花在刀刃上，免费额度用来刷重复**。
> 重复学习是记忆之王，多平台对比能打破单一模型的口径局限。

## 为什么双轨

| 痛点 | 双轨解法 |
|:----|:----|
| 智能体按 token 收费，重复提问很烧钱 | 重复类需求全部挪到网页版免费额度 |
| 单一模型讲法容易「不听话」（不够大白话） | 多平台对比：dp 讲一遍、kimi 讲一遍、千问讲一遍 |
| 重复阅读才能加深记忆 | 同一个知识点，换着平台免费刷 3 遍 |
| 智能体擅长结构化，网页版擅长闲聊式讲透 | 各干各的，互不抢活 |

## 轨道分工表

| 任务 | 走哪条轨道 | 原因 |
|:----|:----|:----|
| 首次讲解新知识点 | 🤖 智能体 | 需要按你的笔记和学段定制 |
| 写笔记 / 整理公式表 | 🤖 智能体 | 要直接读写 vault 文件 |
| 出题 + 批改 + 错题归档 | 🤖 智能体 | 需要结合你的历史错题 |
| **「再讲大白话一点」** | 🌐 网页版 | 改写类需求免费做，不烧 token |
| **重复提问同一个知识点** | 🌐 网页版 | 刷重复，加深记忆 |
| **多平台对比阅读** | 🌐 网页版 | 打破单一口径 |
| 考前快速过知识点 | 🌐 网页版 | 免费额度足够刷 |
| 学习记录 / 日志管理 | 🤖 智能体 | 要写文件 |

## 标准学习闭环（7 步工作流）

```
① 🤖 智能体首讲：大白话 + 例子 + 口诀，并沉淀为笔记
② 🌐 网页版复读：同一知识点去 dp/kimi/千问 各问一遍
③ 🧠 对比归纳：三家讲法哪里不一样？哪个比喻最懂你？记到笔记「补充理解」区
④ 🤖 智能体出题：按笔记原创命题，检验真实掌握度
⑤ 🌐 网页版验算：拿同一道题去网页版让别的模型解，对照思路
⑥ 🤖 错题归档：错题进 03_错题本，附错误原因
⑦ 🌐 隔天免费复习：草稿区/错题本里的题去网页版重刷一遍
```

一句话：**智能体负责「学进去」，网页版负责「忘不了」。**

## 图片题怎么办（草稿区看图工作流）

网页版 AI 大多看不了图，模板用「先转文字再上网」解决：

```
① 题目截图粘贴到 99_草稿区/（图片自动进 90_图片/）
② 智能体跑 tools/vision.py 把截图转成纯文字题目（只填一个 api_key）
③ 复制文字题目 → 去 dp/kimi/千问网页版免费问
④ 草稿区定期清空
```

## 网页版复读提示词模板

直接复制到任意网页版 AI：

```text
用大白话解释【知识点】，要求：
1. 先用一个生活比喻
2. 再给一个具体数字例子，算到底
3. 最后给我 3 句话的记忆口诀
```

```text
我刚学了【知识点】，请出 3 道题考我（由易到难），
我答完你再公布答案和步骤。
```

```text
关于【知识点】我的理解是：（你的理解）
哪里有漏洞？用追问的方式帮我发现，不要直接给答案。
```

## 省 token 技巧

1. **改写类需求不进智能体**：嫌讲得不够通俗 → 网页版免费改
2. **上下文控制**：智能体长对话定期开新会话，让 AI 先读笔记文件恢复上下文，而不是无限续聊
3. **模型分级**：重活（写长笔记/出全套题）用强模型档位，杂活（问个小问题）切便宜/免费档位
4. **笔记是缓存**：让智能体把讲过的东西沉淀成笔记，下次让它「先读笔记再答」，别让它在长对话里重新推理
