# 🆘 新手卡壳速查（装到一半卡住？先看这页）

> 所有「装不上 / 连不上 / 找不到」的常见坑都集中在这。按症状找，找不到再看 [[docs/00_AI安装助手.md|AI 安装剧本]] 的故障速查 或 [[docs/01_环境安装.md|环境安装教程]] 的常见问题。
> 排查口诀：**报错带 timeout / ECONNRESET / 超时 ≈ 网络问题；带 401 / 404 / 找不到文件 ≈ 配置问题。**

## 一、装不上（安装期）

| 症状 | 处理 |
|:----|:----|
| Obsidian 设置里找不到「第三方插件」 | 先随便打开一个笔记仓库（本模板目录），「设置 → 第三方插件」才会出现；入口在左侧边栏底部「设置」齿轮 |
| 插件商店搜不到 Claudian / Image Toolkit / Surfing | 社区商店未必收录全部插件。改用 **AI 代装**（终端对 AI 说「帮我装 Obsidian 的三个插件」），或从插件 GitHub Releases 手动下载 `main.js / manifest.json / styles.css` 放进 `.obsidian/plugins/<插件ID>/` |
| 插件装了但显示灰色没启用 | 设置 → 第三方插件 → 右上角把「限制模式/安全模式」关掉（这是总开关），再逐个点开已装插件的启用开关 |
| `python` 不是内部命令 | Windows 装 Python 时勾选 **"Add python.exe to PATH"**；装完重开终端；或改用 `python3` |
| `node` 不是内部命令 | Node.js 选 LTS 版一路默认安装（会自动加 PATH），装完重开终端 |
| `npm install` 很慢 / 卡住 | 国内网络问题 → 见下方「国内网络加速」 |
| `git clone` 超时 / 连不上 GitHub | 见下方「国内网络加速」 |

## 二、连不上（配置期）

| 症状 | 处理 |
|:----|:----|
| Claudian 连不上 CLI | 先在终端直接跑 `claude`，能对话 = CLI 没问题，是 Claudian 设置里的 **CLI 路径 / 后端没选 `claude`** |
| `claude` 不是内部命令 | npm 没装成功或装到了别的 Node 目录。重跑 `npm install -g @anthropic-ai/claude-code`，装完重开终端 |
| 切换供应商不生效 | 环境变量在会话启动时读取 → **重启 Claudian 对话面板 / 重开终端** |
| 报 401 / 403 | 401 = Key 填错；403 = 服务没开通。检查 `tools/vision_config.json` 和 CC Switch 里填的 Key 是否复制干净（别带多余空格） |
| `vision.py` 报 404 | `base_url` 写错——必须指向 **OpenAI 兼容端点**；普通平台一般以 `/v1` 结尾，**百炼是 `compatible-mode/v1`（不要带结尾斜杠）** |
| `vision.py` 提示找不到 vision_config.json | 忘了复制模板：把 `tools/vision_config.example.json` 复制一份改名为 `vision_config.json`，再填 key |
| CC Switch 添加供应商连不上 | 先确认网络；端点务必照 [[docs/01_环境安装.md|第 4 节表格]] 填 |

## 三、用不对（使用期）

| 症状 | 处理 |
|:----|:----|
| AI 上课不按「大白话 → 例子 → 出题 → 口诀」 | 还没「初始化」。对 AI 说「**初始化**」，完成画像 + 规则 + 看图三任务后再开课 |
| 笔记公式渲染乱码 | 用了 `<details>` 折叠（会阻断 KaTeX）→ 全部换成 `> [!答案]-` Obsidian 原生折叠 |
| 图片粘贴不自动进 `90_图片/` | 附件路径模板已预置；若没生效：设置 → 文件与链接 → 附件默认存放路径 → 指定 `90_图片/` |
| 网页版 AI 看不了我发的图 | DeepSeek 网页版本来就不支持图片输入 → 用看图助手：截图放 `90_图片/` → 让 AI 跑 `tools/vision.py` 转成文字 → 再拿去网页版问 |
| `vision.py` 中文路径报错 | 图片路径尽量别带中文 / 空格，或改用英文文件名（如 `img1.png`） |

## 四、国内网络加速（很多卡住其实是网络）

| 场景 | 处理 |
|:----|:----|
| npm 装包慢 | `npm config set registry https://registry.npmmirror.com`（国内镜像）；想还原：`npm config set registry https://registry.npmjs.org` |
| git clone GitHub 慢 / 断 | 加镜像前缀：`git clone https://gh-proxy.com/https://github.com/65316/AI-Tutor.git`；或直接浏览器 Download ZIP |
| 插件 GitHub Releases 下载不动 | 用 gh-proxy.com 前缀加速，或回 Obsidian 商店直接搜装 |
| Claude Code 装好后连不上 | Claude Code 只是「外壳」，你用的是 CC Switch 里配的**国内平台**（DeepSeek / Kimi / GLM / 百炼），不直连 Anthropic 官方，不存在"连不上官方"的问题 |
