# 环境安装教程

> 目标：15 分钟内搭好「Obsidian + AI 智能体 + 网页版免费对话」完整学习环境。
> 本教程只涉及公开软件与官方端点，所有密钥请填你自己的。

## 0. 你将搭出什么

```
Obsidian（笔记 + 内置浏览器）
├── Claudian 插件 → 调用本机的 Claude Code / Codex CLI
│      └── 供应商可切换：DeepSeek / Kimi / GLM / 千问 / 中转站
└── 浏览器书签 → DeepSeek / Kimi / 千问 网页版（免费额度）
```

## 1. 安装 Obsidian

1. 官网 https://obsidian.md 下载对应系统版本，安装
2. 「打开本地仓库文件夹」→ 选择本仓库克隆后的文件夹
3. 首次打开会自动生成剩余 `.obsidian/` 配置（本模板已预置附件路径：图片粘贴自动存 `90_图片/`，无需手动设置）
4. **装两个社区插件**（设置 → 第三方插件 → 浏览）：
   - **Image Toolkit**：笔记里点击图片即浮现放大镜大图，可缩放拖动——看题目截图神器
   - **Surfing**：给 Obsidian 加一个内置浏览器标签页，网页版 AI 直接在笔记软件里开

## 2. 安装 Claude Code CLI

需要 Node.js 18+（https://nodejs.org 下载 LTS 版）：

```bash
npm install -g @anthropic-ai/claude-code
claude --version   # 验证安装
```

## 3. 安装 Claudian 插件（Obsidian 里对话）

1. Obsidian 设置 → 第三方插件 → 关闭安全模式 → 浏览社区插件
2. 搜索 **Claudian** → 安装 → 启用
3. Claudian 设置里选择后端为 `claude`（本机 CLI），以后可以随时切 `codex`

效果：Obsidian 侧边栏出现对话面板，AI 直接读写你的笔记文件。

## 4. 配置供应商（多选一或随时切换）

Claude Code 通过两个环境变量指向任意「Anthropic 兼容」服务：

```bash
export ANTHROPIC_BASE_URL="https://端点地址"
export ANTHROPIC_AUTH_TOKEN="YOUR_API_KEY"
```

| 平台 | Anthropic 兼容端点 | API Key 获取 |
|:----|:----|:----|
| **DeepSeek 官方** | `https://api.deepseek.com/anthropic` | platform.deepseek.com |
| **Moonshot Kimi** | `https://api.moonshot.cn/anthropic` | platform.moonshot.cn |
| **智谱 GLM** | `https://open.bigmodel.cn/api/anthropic` | bigmodel.cn（有免费模型档） |
| **阿里百炼（千问）** | `https://dashscope.aliyuncs.com/apps/anthropic` | bailian.console.aliyun.com |
| **第三方中转站** | `https://YOUR_PROXY_URL`（自行填写） | 自行购买 |

> ⚠️ 注意：
> - 百炼端点**不要以 `/v1/` 结尾**；其 Coding Plan 专属 Key 走 `coding-intl` 专用端点，普通 Key 不通用
> - 第三方中转站请自行评估可靠性，**Key 只存本机，不要提交到任何仓库**

### 图形化切换（推荐）：CC Switch

逐个改环境变量太麻烦，可用开源工具 **CC Switch**（GitHub 搜 cc-switch）：
- 把上表每个平台保存为一个供应商条目（名称 + 端点 + YOUR_API_KEY）
- 一键切换当前使用的供应商，Claudian 下次对话即生效

## 5.（可选）Codex 双智能体

Claudian 同时支持 OpenAI Codex CLI 作为后端：

```bash
npm install -g @openai/codex
```

配置好 Codex 的供应商后，在 Claudian 设置里切换 `claude` / `codex`，两个智能体共用同一套 vault 规则。

## 7. 看图助手（视觉 API，解决网页版看不了图）

DeepSeek 网页版免费但**不支持图片输入**。本模板内置 `tools/vision.py`：把图片发给视觉模型，转成文字题目，再拿去网页版免费提问。

**默认方案：阿里云百炼（推荐，新用户有免费额度）**

1. 打开 https://bailian.console.aliyun.com ，注册/登录阿里云账号
2. 开通百炼模型服务 —— **新用户各模型自动赠送免费额度**（视觉模型也有，以官网额度页为准），不绑定付费计划也能先用
3. 控制台里创建 API Key 并复制
4. 编辑 `tools/vision_config.json`，把 key 粘进去：

```json
{
  "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
  "api_key": "YOUR_API_KEY",   ← 换成你的百炼 Key
  "model": "qwen-vl-max"
}
```

验证：

```bash
python tools/vision.py "90_图片/任意一张图.png" "图里写了什么？"
```

### 备选方案（免费额度用完/不想用阿里云）

| 平台 | base_url（OpenAI 兼容） | 视觉 model 示例 | 备注 |
|:----|:----|:----|:----|
| **阿里云百炼**（默认） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-vl-max` | 新用户免费额度，用完按量计费很便宜 |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4.6v` | 有免费模型档 |
| 你的中转站 | `https://YOUR_PROXY_URL/v1` | 看站点支持的视觉模型 | 自行评估可靠性 |

> 🔒 安全：`vision_config.json` 入库时只有占位符。你填了真实 key 之后，如果要把仓库推到自己的公开托管，记得把它加进 `.gitignore`。

## 8. 初始化 + 启动验证

```bash
cd 我的笔记本
claude
```

1. 对 AI 说：**「初始化」** → 它带你完成三个任务：①完善学员画像 ②定制学习规则 ③搭建看图助手（就是第 7 步的 key）
2. 然后说：**「帮我学 C 语言指针」**——如果它按「大白话 → 例子 → 出题 → 口诀」开讲，系统就跑通了

## ❓ 常见问题

- **Claudian 连不上 CLI？** 先在终端直接跑 `claude` 确认 CLI 本身可用，再检查 Claudian 设置里的 CLI 路径
- **切换供应商不生效？** 重启 Claudian 对话面板（环境变量在会话启动时读取）
- **公式渲染乱码？** 检查笔记是否用了 `<details>`（会阻断 KaTeX），全部换成 `> [!答案]-` 折叠块
