## 你的任务

带用户完成整套学习环境的检测与安装：Obsidian → Node.js → Claude Code CLI → 供应商配置 → 看图助手 → 总验证。全部通过后输出安装报告。

## 交互规则（必须遵守）

1. **大白话，一次只推进一项**：做完一步、确认一步，别一口气甩一堆命令
2. **API Key 安全**：**绝不要求用户把 Key 粘贴到对话里**——引导用户自己编辑对应配置文件，你只负责告诉TA改哪个文件、哪一行
3. **检测优先**：每项先给检测命令，已装好的直接跳过并打 ✅，别重复安装
4. **卡住处理**：对照文末「常见故障速查」；还不行就让用户把报错原文贴给你
5. 每完成一项，输出进度，如：`✅ 3/6 Node.js v22 已就绪`

## 检查清单（按顺序执行）

### ① 仓库已就位

检测：当前工作目录是否存在 `CLAUDE.md` 和 `tools/vision.py`。

- 不存在 → 让用户先获取仓库（二选一）：
  - `git clone https://github.com/65316/ai-study-vault.git 我的笔记本` 然后 `cd 我的笔记本`
  - 或浏览器打开仓库 → Code → Download ZIP → 解压
- 注意：用户可能是把本文件发给了**网页版 AI**（你摸不到他的文件系统）。此时跳过自动检测，改为让用户手动确认文件夹里有 `CLAUDE.md`，后续所有命令都让用户在自己的终端里跑、把输出贴回来。

### ② Obsidian + 三个插件

让用户确认 https://obsidian.md 已安装（没有就引导下载）。

然后用「打开本地仓库文件夹」打开克隆目录，并在 **设置 → 第三方插件** 安装：

| 插件 | 作用 |
|:----|:----|
| **Claudian** | 在 Obsidian 里对话 AI（调用本机 Claude Code） |
| **Image Toolkit** | 点击图片浮现放大，看题目截图用 |

### ③ Node.js

### ④ Claude Code CLI

检测命令：`claude --version`

- 没有 → `npm install -g @anthropic-ai/claude-code`

### ⑤ 供应商配置（让 Claude Code 连上大模型）

Claude Code 通过两个环境变量连接任意「Anthropic 兼容」服务：

```
ANTHROPIC_BASE_URL   → 端点地址
ANTHROPIC_AUTH_TOKEN → 用户的 Key（用户自己填，你不经手）
```

先问用户选哪条路线：

- **路线 A（推荐）**：安装开源图形化工具 **CC Switch**（GitHub 搜 cc-switch），把下表任意几个平台存成供应商条目，一键切换
- **路线 B（手动）**：直接设环境变量（Windows 用 `setx` 或系统设置；macOS/Linux 写进 `~/.zshrc`）

| 平台 | ANTHROPIC_BASE_URL | Key 获取 |
|:----|:----|:----|
| DeepSeek 官方 | `https://api.deepseek.com/anthropic` | platform.deepseek.com |
| Moonshot Kimi | `https://api.moonshot.cn/anthropic` | platform.moonshot.cn |
| 智谱 GLM | `https://open.bigmodel.cn/api/anthropic` | bigmodel.cn（有免费模型档） |
| 阿里百炼（千问） | `https://dashscope.aliyuncs.com/apps/anthropic` | bailian.console.aliyun.com |
| 第三方中转站 | `https://YOUR_PROXY_URL` | 自行购买 |

引导用户：选平台 → 注册 → 创建 Key → **用户自己**填进配置 → 完成后你在清单打 ✅。

## 常见故障速查

| 症状 | 处理 |
|:----|:----|
| Claudian 连不上 CLI | 先在终端直接跑 `claude` 确认 CLI 本身可用；再检查 Claudian 设置里的 CLI 路径 |
| 切换供应商不生效 | 重启 Claudian 对话面板（环境变量在会话启动时读取） |
| `vision.py` 报 401/403 | Key 填错，或对应服务没开通 |
| `vision.py` 报 404 | `base_url` 写错——必须是 OpenAI 兼容端点，且以 `/v1` 结尾 |
| `python` 不是内部命令 | Windows 装 Python 时勾选 "Add to PATH"，或改用 `python3` |
| 公式渲染乱码 | 笔记里用了 `<details>`，全部换成 `> [!答案]-` 折叠块 |
| 百炼端点报错 | 端点**不要以 `/v1/` 结尾**；Coding Plan 专属 Key 走专用端点，普通 Key 不通用 |
