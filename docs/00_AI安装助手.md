## 检查清单（按顺序执行）

### ① 仓库已就位

检测：当前工作目录是否存在 `CLAUDE.md` 和 `tools/vision.py`。

- 不存在 → 让用户先获取仓库（二选一）：
  - `git clone https://github.com/65316/ai-study-vault.git 我的笔记本` 然后 `cd 我的笔记本`
  - 或浏览器打开仓库 → Code → Download ZIP → 解压
- 注意：用户可能是把本文件发给了**网页版 AI**（你摸不到他的文件系统）。此时跳过自动检测，改为让用户手动确认文件夹里有 `CLAUDE.md`，后续所有命令都让用户在自己的终端里跑、把输出贴回来。

### ② Obsidian + 三个插件（AI 可代装）

让用户确认 https://obsidian.md 已安装（没有就引导下载），并已用「打开本地仓库文件夹」打开克隆目录（这样 `.obsidian/` 目录才存在）。

**AI 代装（有终端权限时直接执行）**——插件本质就是三个文件，放进 `.obsidian/plugins/<插件ID>/` 即可：

| 插件 ID | 来源 repo | 作用 |
|:----|:----|:----|
| `realclaudian` | yishentu/claudian | 在 Obsidian 里对话 AI（调用本机 Claude Code） |
| `obsidian-image-toolkit` | obsidian-community/obsidian-image-toolkit（若 301 就跟随重定向） | 点击图片浮现放大，看题目截图用 |
| `surfing` | pkm-er/Obsidian-Surfing | 内置浏览器标签页，开 AI 网页版 |

每个插件执行：

```bash
# 1. 建目录
mkdir -p ".obsidian/plugins/<插件ID>"
# 2. 从最新 release 下载三件套（main.js / manifest.json / styles.css）
curl -sL https://api.github.com/repos/<repo>/releases/latest   # 从 assets 取 browser_download_url 逐个下载到上面目录
# 3. 登记（首次创建即可；文件已存在则把缺失的 ID 合并进去）
echo '["obsidian-image-toolkit", "realclaudian", "surfing"]' > .obsidian/community-plugins.json
```

- 下载不通（网络被墙）→ 降级：让用户在 Obsidian「设置 → 第三方插件 → 浏览」手动搜装（Obsidian 自家 CDN 有时反而能通）
- ⚠️ **最后一步必须用户亲手（GUI）**：重启 Obsidian → 设置 → 第三方插件 → **关闭「限制模式」（旧版叫安全模式）** → 确认三个插件已启用。AI 代装只能到文件层，开关在这里

### ⑤ 供应商配置（让 Claude Code 连上大模型）

Claude Code 通过两个环境变量连接任意「Anthropic 兼容」服务：

```
ANTHROPIC_BASE_URL   → 端点地址
ANTHROPIC_AUTH_TOKEN → 用户的 Key（用户自己填，你不经手）
```

先问用户选哪条路线：

- **路线 A（推荐）· CC Switch 图形化切换 —— AI 可代劳下载安装**：
  1. 检测是否已装：`winget list --id farion1231.CC-Switch`（或问用户开始菜单有没有 CC Switch）
  2. **Windows（AI 直接执行）**：`winget install -e --id farion1231.CC-Switch`（winget 官方源，无需手动下载）
     - winget 不可用/失败 → 从 https://github.com/farion1231/cc-switch/releases 下载对应安装包（`.exe`/`.msi`）手动装
  3. **macOS**：winget 不可用 → 从上面 releases 页下载 `.dmg` 拖进 Applications
  4. 装好后用户打开 CC Switch → 自己点「添加供应商」→ 选平台 → **自己粘贴**端点和 Key（AI 不经手 Key）→ 设为当前供应商
- **路线 B（手动）**：直接设环境变量（Windows 用 `setx` 或系统设置；macOS/Linux 写进 `~/.zshrc`）

| 平台 | ANTHROPIC_BASE_URL | Key 获取 |
|:----|:----|:----|
| DeepSeek 官方 | `https://api.deepseek.com/anthropic` | platform.deepseek.com |
| Moonshot Kimi | `https://api.moonshot.cn/anthropic` | platform.moonshot.cn |
| 智谱 GLM | `https://open.bigmodel.cn/api/anthropic` | bigmodel.cn（有免费模型档） |
| 阿里百炼（千问） | `https://dashscope.aliyuncs.com/apps/anthropic` | bailian.console.aliyun.com |
| 第三方中转站 | `https://YOUR_PROXY_URL` | 自行购买 |

引导用户：选平台 → 注册 → 创建 Key → **用户自己**填进配置 → 完成后你在清单打 ✅。

### ⑥ 看图助手（视觉 API）

先检测 Python（`vision.py` 依赖）：`python --version` 或 `python3 --version`（需 3.8+）
- 没有 → 引导去 https://www.python.org/downloads/ 安装，**Windows 务必勾选 "Add python.exe to PATH"**

再检测：`tools/vision_config.json` 是否存在，且 `api_key` 是否还是 `YOUR_API_KEY`。

- 文件不存在 → 让用户复制 `tools/vision_config.example.json` 改名为 `tools/vision_config.json`（你有终端权限可直接 `cp tools/vision_config.example.json tools/vision_config.json`）
- `api_key` 还是 `YOUR_API_KEY` → 引导开通**阿里云百炼**（默认方案，新用户各模型自动送免费额度）：
  1. 打开 https://bailian.console.aliyun.com 注册/登录
  2. 开通模型服务 → 创建 API Key
  3. **用户自己**编辑 `tools/vision_config.json` 填入 Key（默认值已是百炼端点 + `qwen-vl-max`，不用改）
- 验证：让用户往 `90_图片/` 随便放一张截图（题目/书页/任意），然后跑：
  ```bash
  python tools/vision.py "90_图片/那张图.png" "图里写了什么？"
  ```
  输出图片内容即通过。（备选平台见 `docs/01_环境安装.md` 第 7 节）

## 常见故障速查

| 症状 | 处理 |
|:----|:----|
| Claudian 连不上 CLI | 先在终端直接跑 `claude` 确认 CLI 本身可用；再检查 Claudian 设置里的 CLI 路径 |
| 切换供应商不生效 | 重启 Claudian 对话面板（环境变量在会话启动时读取） |
| `vision.py` 报 401/403 | Key 填错，或对应服务没开通 |
| `vision.py` 报 404 | `base_url` 写错——必须是 OpenAI 兼容端点，且以 `/v1` 结尾 |
| `python` 不是内部命令 | Windows 装 Python 时勾选 "Add to PATH"，或改用 `python3` |
| 公式渲染乱码 | 笔记里用了 `<details>`，全部换成 `> [!答案]-` 折叠块 |
| 百炼端点报错 | 端点**不要以 `/v1/` 结尾**；Coding Plan 专属 Key 走专用端点，普通 Key 不通用 |

> 装不上 / 连不上 / 找不到还有更多？让用户看 `docs/04_新手卡壳速查.md`（含国内加速），或把报错原文贴给你。
