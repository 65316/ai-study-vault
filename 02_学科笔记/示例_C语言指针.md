# 示例笔记：C 语言指针

> 这篇展示本系统的标准笔记格式：四步循环产出 + 三段式结构 + 可折叠答案。
> 让 AI 讲新知识点时，产出就是这个样子。

## ① 大白话解释

**指针就是「存门牌号的纸条」。**

- 变量是一个房间，房间里住着值（比如 `a = 5`，房间 a 里住着 5）
- 指针变量是一张纸条，上面写的不是值，而是**别的房间的门牌号**（地址）
- 顺着纸条找上门，就能看住在这个房间里的值，甚至换个人住（改值）

## ② 具体例子

```c
int a = 5;        // 房间 a，住着 5
int *p = &a;      // 纸条 p，写着 a 的门牌号（& 意思是"取地址"）
*p = 10;          // 顺着纸条找上门，把 a 家的 5 换成 10（* 意思是"顺着去"）
printf("%d", a);  // 打印 a → 输出 10，a 真的被改了！
```

## ③ 出题检验

### 题 1 — 下列代码输出什么？

```c
int x = 3;
int *p = &x;
*p = *p + 7;
printf("%d", x);
```

> [!答案]- 点击展开
>
> **① 分析：**
> `p` 存的是 `x` 的地址，`*p` 就是 `x` 本身。
>
> **② 代入：**
> `*p = *p + 7` 等价于 `x = x + 7`，即 `x = 3 + 7`。
>
> **③ 结果：**
> 输出 `10`。
>
> **计算步骤总结：**
> - 第一步：`&x` 取地址，`p` 指向 `x`
> - 第二步：`*p` 等价于 `x`
> - 第三步：对 `*p` 赋值就是改 `x`

### 题 2 — 找错

```c
int *p;
*p = 5;
printf("%d", *p);
```

> [!答案]- 点击展开
>
> **原命题：** 上面代码能正常运行吗？
>
> **判断：** ❌ 错，这是**野指针**。
>
> **解析：** `p` 声明时没初始化，里面是随机地址。`*p = 5` 是往随机地址写值，程序可能崩溃。
>
> **正确做法：**
> ```c
> int a;          // ❌ 错误示范：不分配房子就往门牌号里塞人
> int *p = &a;    // ✅ 先让 p 指向一个真实的变量
> *p = 5;
> ```
>
> **计算步骤总结：**
> - 第一步：指针使用前**必须初始化**（指向真实变量或 NULL）
> - 第二步：先有「房间」，纸条才有意义

## ④ 口诀与速查

**口诀**：`&` 取地址，`*` 顺藤摸瓜；纸条不指门，写字就塌家。

| 符号 | 名字 | 意思 |
|:----|:----|:----|
| `&x` | 取地址 | 拿到 x 的门牌号 |
| `*p` | 解引用 | 顺着纸条找上门 |
| `int *p` | 声明指针 | p 是一张「只写 int 门牌号」的纸条 |
